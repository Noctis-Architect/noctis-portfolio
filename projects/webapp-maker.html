Production-Grade Web-to-Android Engine

webapp-maker is an open-source, robust Android wrapper template designed to transform progressive web applications and responsive sites into sleek, production-ready Android APKs with native features, offline fallbacks, and push notifications.

Technical Capabilities

  • Hardware-Accelerated WebView: Fine-tuned Chromium WebView configurations including hardware acceleration, DOM storage optimization, custom WebChromeClient file pickers, and geolocation delegates.
  • Native Navigation & Back Button Handling: Seamlessly manages system back-press events by walking the WebView history tree rather than accidentally terminating the application.
  • Offline Fallbacks & Pull-to-Refresh: Detects network loss with broadcast receivers, rendering localized, friendly offline views and integrating native swipe-to-refresh controls.
  • Push Notification Integration: Pre-integrated hooks for Firebase Cloud Messaging (FCM) and OneSignal, supporting deep linking to target pages from incoming notifications.

Tech Stack

Java / Kotlin, Android SDK, AndroidX WebKit, Firebase Cloud Messaging, Gradle build system.
